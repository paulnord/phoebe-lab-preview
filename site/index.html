A QUICK START

Read an eclipse

As one star passes in front of the other, the total light drops. The two eclipses encode the stars’ relative sizes, temperatures, and orbital geometry.

  1. Change inclination. Near 90°, the orbit is edge-on. Lowering it can make the eclipses shallower or remove them.
  2. Change the radii. Larger stars generally produce broader eclipses. Radius and inclination can partly mimic one another.
  3. Change the temperature ratio. Watch the relative depths of the primary and secondary eclipses.
  4. Look at the residuals. A good-looking overlay can still hide a systematic mismatch. The lower panel makes that mismatch visible.

What is actually running? PHOEBE’s Python and compiled numerical code run in a WebAssembly worker on your device. A preview uses a coarser mesh and fewer phases. Refined mode computes a denser model. Spherical models are the starting point. Adding tidal distortion can take minutes; changing several controls queues only the latest model. There is no model-computation server.

This first version explores detached binaries in Johnson V. Photometry alone cannot reliably determine every physical parameter. Use radial velocities and other constraints for a full scientific analysis.

Primary mass: 1.2 solar masses. Primary temperature: 6,300 K. The star illustration is a size guide.
